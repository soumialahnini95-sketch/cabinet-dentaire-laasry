# Cabinet dentaire Laasry Anas — site vitrine

Site statique autonome à déposer à la racine de votre dépôt GitHub Pages. Ouvrez `index.html` avec Live Server pour tester le site.

## Prise de rendez-vous
Le formulaire ouvre WhatsApp vers +212 601 391 918 avec le message renseigné par le patient. Aucun rendez-vous n’est confirmé automatiquement, aucun dossier médical n’est stocké.

## Vérifications éditoriales avant diffusion
- Les images de comparaison fournies sont présentées comme **illustrations**, et non comme des résultats cliniques réels. Pour publier des résultats médicaux authentiques, fournir les photographies originales avec le consentement approprié.
- Aucun témoignage fictif n’est affiché ; la section Avis renvoie à Google.
- Vérifier que les réseaux sociaux et le numéro appartiennent au cabinet.
- Le site contient encore `noindex,nofollow` : retirer cette directive seulement quand le cabinet autorise l’indexation Google.
- Vérifier toutes les descriptions de soins et les autorisations des photos avant mise en ligne publique.
